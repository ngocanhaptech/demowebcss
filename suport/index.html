Tài liệu quản trị

Hướng dẫn quản trị website Flatsome

Tài liệu dành cho quản trị viên nội dung: cách quản lý Bài viết (Posts), Trang (Pages), Thư viện ảnh (Media) và Khối nội dung dùng lại (UX Blocks) trên theme Flatsome.

1. Tổng quan hệ thống

Bốn khu vực quản trị chính và khi nào dùng loại nội dung nào.

Post (bài viết)
Nội dung dạng tin tức/blog, có ngày đăng và chuyên mục. Dùng cho: tin tức, thông báo, bài chia sẻ.
Page (trang)
Nội dung tĩnh, không gắn ngày. Dùng cho: Trang chủ, Giới thiệu, Liên hệ, Landing page.
Media
Thư viện lưu trữ toàn bộ ảnh/video đã tải lên, dùng chung cho cả Post và Page.
UX Block
Khối nội dung tạo một lần, chèn lại được ở nhiều Post/Page/Widget/Footer khác nhau.
Hai chế độ chỉnh sửa Trình soạn thảo WordPress mặc định dùng cho nội dung chữ đơn giản; nhấn Edit with UX Builder khi cần dàn Section/Row/Column, chèn ảnh nền, Block, v.v.

Có thể lọc theo Category, Tag hoặc trạng thái (Published/Draft/Trash) bằng bộ lọc phía trên danh sách.

Thêm bài viết mới

Post → Add New
  • Nhập tiêu đề, gán Category và Tag phù hợp ở cột bên phải.
  • Chọn Featured Image — ảnh này hiển thị ở danh sách blog và khi chia sẻ lên mạng xã hội.
  • Nhấn Edit with UX Builder để dàn nội dung trực quan, hoặc soạn trực tiếp bằng trình soạn thảo mặc định.

Thiết lập trang Blog

Kiểu hiển thị danh sách bài viết (dạng lưới, danh sách, số cột…) được cấu hình chung tại Theme Options → Blog, áp dụng cho toàn bộ trang blog.

Sửa trang bằng UX Builder

Nhấn Edit with UX Builder để dàn nội dung theo Section → Row → Column (xem chi tiết trong tài liệu "Hướng dẫn chỉnh sửa UX Builder").

Gán trang làm Trang chủ

Settings → Reading → A static page

Chọn trang cần làm Trang chủ (Homepage) và trang hiển thị danh sách bài viết (Posts page) nếu muốn tách riêng hai trang này.

Landing page Với các trang quảng cáo/landing page muốn ẩn tiêu đề hoặc ẩn header-footer mặc định, dùng mục Page Options ở cuối trang chỉnh sửa.

4. Quản lý Media thư viện ảnh

Tải ảnh đúng chuẩn giúp trang tải nhanh và hiển thị sắc nét trên mọi thiết bị.

Media → Library
wp-admin/upload.php

Chuẩn ảnh khi tải lên

  • Định dạng ưu tiên: JPG cho ảnh chụp, PNG cho ảnh có nền trong suốt, WebP nếu cần dung lượng nhẹ.
  • Nén ảnh trước khi tải lên (giữ dưới ~500KB/ảnh) để trang không bị chậm.
  • Trong UX Builder, phần Ảnh nền luôn chọn Size = Original để có chất lượng cao nhất — trình duyệt tự co giãn theo khung hiển thị.

Thay ảnh mà không vỡ link

Chọn ảnh trong Media Library → Replace Media (nếu có cài plugin hỗ trợ) để tải ảnh mới đè lên ảnh cũ, mọi nơi đang dùng ảnh đó sẽ tự cập nhật mà không cần chèn lại từng vị trí.

Khi nào cần Regenerate Thumbnails

Sau khi đổi theme hoặc thay đổi kích thước ảnh đại diện mặc định, các ảnh cũ có thể hiển thị sai tỉ lệ. Lúc này cần chạy chức năng Regenerate Thumbnails (qua plugin hoặc WP-CLI) để tạo lại toàn bộ kích thước ảnh thu nhỏ cho ảnh đã tải lên trước đó.

Dọn dẹp định kỳ Xóa ảnh không còn dùng trong thư viện để tiết kiệm dung lượng lưu trữ — kiểm tra kỹ ảnh không còn gắn ở Post/Page nào trước khi xóa.

5. Quản lý UX Blocks nội dung dùng lại

UX Block là khối nội dung tạo một lần và chèn lại được ở nhiều nơi — CTA, banner, bảng giá, footer tùy chỉnh…

Tạo Block mới

  1. 1

    Vào UX Blocks → Add New

    Mục UX Blocks chỉ hiển thị trên menu khi theme Flatsome đang active.

  2. 2

    Đặt tên Block

    Ví dụ: "CTA liên hệ", "Banner khuyến mãi" — tên này chỉ để quản trị viên nhận diện, không hiển thị ngoài site.

  3. 3

    Dàn nội dung bằng UX Builder

    Nhấn Edit with UX Builder, thêm Text/Image/Button như một trang bình thường.

  4. 4

    Lưu lại

    Nhấn Apply rồi Update.

Chèn Block vào trang

Trong UX Builder của Post/Page, bấm nút + để thêm phần tử → tìm từ khóa Block → chọn Block đã tạo từ danh sách thả xuống → Apply → Update.

Sửa Block đang dùng ở nhiều nơi

Lưu ý quan trọng Một Block có thể đang được chèn ở nhiều Post/Page khác nhau. Khi sửa nội dung Block, thay đổi sẽ áp dụng đồng thời cho tất cả các vị trí đang dùng — nên kiểm tra trước khi sửa nếu không chắc Block đang xuất hiện ở đâu.

Dùng Block cho Footer & Widget

  • Footer tùy chỉnh: tạo Block riêng → vào Theme Options → Footer → chọn Block đó áp dụng cho toàn site.
  • Widget: vào Appearance → Widgets → kéo widget Flatsome Block vào khu vực mong muốn → chọn Block cần hiển thị.

6. Phụ lục: Lỗi thường gặp

Màn hình trắng khi bấm UX Builder
Thường do plugin cache hoặc xung đột plugin. Thử tắt cache, kiểm tra lại; nếu vẫn lỗi, tắt thử từng plugin không cần thiết.
Ảnh vỡ layout trên di động
Kiểm tra lại Size ảnh (nên là Original) và không dùng ảnh có tỉ lệ quá khổ so với khung chứa.
Sửa Block xong không thấy đổi trên trang
Xóa cache trình duyệt hoặc cache của plugin cache đang cài trên site (nếu có), sau đó tải lại trang.
