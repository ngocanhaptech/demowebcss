TICKET 4.2

Login API & JWT Session Creation

High
Summary

[Auth] Implement POST /api/auth/login with JWT cookie

Context

Xử lý đăng nhập và cấp token session.

Tasks

  • Create app/api/auth/login/route.ts.
  • Validate credentials (email + password) against DB.
  • If valid:
  • Generate signed JWT (payload: userId, role, exp).
  • Set HTTP-only, Secure, SameSite=Lax cookie named meshflow_session.
  • Return 200 OK.
  • If invalid: Return 401 Unauthorized.

Acceptance Criteria

  • Cookie is set correctly in browser DevTools.
  • JS cannot read the cookie value (HttpOnly).
  • Invalid credentials do not reveal which field was wrong (generic error).

PriorityHigh
TICKET 4.3

Middleware Protection for Admin Routes

High
Summary

[Security] Protect /admin routes with Next.js Middleware

Context

Chặn truy cập trái phép vào giao diện Admin trước khi load page.

Tasks

  • Create/Edit middleware.ts.
  • Match paths starting with /admin.
  • Check for meshflow_session cookie.
  • Verify JWT signature and expiry (using lib/jwt helper).
  • If invalid/expired: Redirect to /admin/login?next=....
  • If valid: Allow request to proceed.
  • Note: Middleware is for routing, not final authorization. Route handlers must double-check.

Acceptance Criteria

  • Unauthenticated user visiting /admin redirects to login.
  • Authenticated user can access /admin.
  • Expired token triggers redirect.
